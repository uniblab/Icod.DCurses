# T1002 — 1.0 Public Contract Carry-Forward

**Release line:** `1.0.0`  
**Candidate:** `1.0.0-rc.1`  
**Source contract:** stable `0.9.0`  
**Status:** compatibility lock active

## Decision

The 1.0 managed public contract is intentionally identical to the public contract frozen by 0.9. The major-version promotion changes package/assembly identity and stability policy; it does not add, remove, rename, or reinterpret public API merely to manufacture a 1.0 delta.

## Machine baseline

Both the historical 0.9 fingerprint and proposed 1.0 fingerprint contain:

```text
sha256:            274b87ec28a253e4891f7f72dea847eaf7d57f45e7b6dd2ae4b464e783046639
exported types:    43
contract lines:   309
```

`docs/Public-API-Fingerprint-0.9.json` remains the historical pre-1.0 freeze record.

`docs/Public-API-Fingerprint-1.0.json` is the proposed stable 1.x baseline.

`PublicApiFingerprintTests` continues to regenerate the canonical compiled contract and reject divergence from the 0.9 freeze. `PublicStableApiBaselineTests` additionally requires the 1.0 baseline to match the 0.9 SHA, counts, and exported-type inventory exactly.

## Semantic carry-forward

The dedicated 0.9 semantic/hardening tests remain authoritative for behavior that reflection does not encode, including:

- zero-based row/column geometry and parent-local subwindow origins;
- rows/columns dimension meaning and argument/range categories;
- half-open terminal-column slicing;
- Unicode 17.0.0 width semantics and East Asian Ambiguous policy;
- wide-cell leader/continuation repair;
- semantic line-glyph identity;
- single-writer logical surfaces;
- Terminal-session ownership transfer;
- caller cancellation versus disposal-unblocked waits;
- EOF mapping;
- partial-output invalidation and safe retry;
- dual failure preservation;
- Terminal-authoritative restoration.

## Dependency boundary

The 1.0 public lower-layer type set remains exactly:

```text
Icod.Terminal.TerminalSession
Icod.Terminal.TerminalEndpoint
Icod.Terminal.TerminalControlResult<T>
Icod.TermInfo.TerminalDescription
Icod.TermInfo.TerminalSize
```

No additional Terminal/TermInfo type is accepted.

## Assembly identity

The release candidate sets `AssemblyVersion` to `1.0.0.0`. This is the intended stable major-version assembly identity. It does not alter the canonical public-signature fingerprint because assembly version metadata is package/identity policy rather than an API member.

## Gate

T1002 is satisfied when the candidate builds/tests/packages for all target frameworks, the canonical public fingerprint remains unchanged, the 1.0 baseline is machine-proven identical to 0.9, and no semantic/dependency freeze test regresses.
