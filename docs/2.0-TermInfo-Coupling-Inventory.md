### Raw-output boundary

The forbidden production path is currently explicit and small:

```text
src/Integration/TerminalOutputShim.cs
    ITerminalOutput.WriteTerminalStringAsync(...)
    TerminalSessionCursesOutput.WriteTerminalStringAsync(...)
    TerminalSession.WriteTerminalStringAsync(...)

src/Internal/TerminalCapabilityWriter.cs
    TerminalCapabilityWriter.WriteAsync(...)

src/Internal/CursesRefreshEngine.cs and resolver callers
    expanded strings passed to TerminalCapabilityWriter
```

T2005/T2007 remove this path. `TerminalSession.Output` and legacy raw terminal-string methods are not acceptable substitutes merely because they are exposed by Terminal 1.x.

## Permanent enforcement required by T2007

The completed migration needs independent guards for all of these boundaries:

1. production source contains no `Icod.TermInfo` symbols, aliases, fully qualified names, legacy `TerminalSession.Terminal`/`GetSize()`/lifecycle `Size` consumption, or raw/borrowed output calls;
2. public signatures recursively contain no TermInfo type;
3. the compiled DCurses assembly has no direct `Icod.TermInfo` assembly reference and no TermInfo metadata type reference;
4. each packed NuGet target-framework dependency group directly names exactly the qualified `Icod.Terminal` dependency;
5. samples, package smoke and fresh package consumers contain no direct TermInfo source/package reference;
6. any remaining test bootstrap exception is path-limited and reviewed; and
7. negative controls prove that reintroducing a direct package, production symbol or public TermInfo signature fails the appropriate guard.

Transitive TermInfo restore presence through Terminal is expected and must not fail these checks.
