# Icod.DCurses 2.3 release readiness

Decision date: 2026-10-09. The implemented feature set is frozen for the stable
2.3.0 release candidate. This record distinguishes verified software behavior
from terminal-emulator presentation characteristics and preserves historical
failure evidence without making it current release policy.

## Candidate boundary

| Item | Stable candidate |
|---|---|
| Source/package version | `2.3.0` |
| Assembly version | `2.0.0.0` |
| Frameworks | .NET 8, 9 and 10 |
| Sole direct runtime dependency | Published stable `Icod.Terminal 1.28.0`; TermInfo transitive |
| Public surface | 105 exported types; 839 canonical contract lines |
| API SHA-256 | `b86ba658fd90d041eeccf5345ecc71a978bea785f0b2bbb9b8274091ccc4afc1` |

The boundary includes cell-aligned `CursesRasterAtlas`, explicit complete-frame
`RefreshRasterAsync`, recoverable presentation-timeout fallback, full-atlas
update coalescing, and the public RasterAtlas sample with supplied 16×16
water/grass/forest/road/player artwork. Source pixels, recreation, gameplay, and
fallback policy remain application-owned.

## Dependency policy

Production declares exactly one direct package dependency:
`Icod.Terminal 1.28.0`. Tests and packaging guards verify the direct dependency
identity and reject direct `Icod.TermInfo` coupling. They intentionally do not
duplicate a particular Terminal version: restore, compilation, and the test
suite are the compatibility proof. The tag workflow reads the declared Terminal
version for release notes and requires it to be present, but does not hard-code
an obsolete version.

## Presentation policy

The sample exposes an application-owned ladder:

| Mode | Selection |
|---|---|
| ATLAS | Verified persistent identities and exact geometry |
| FRAME | Explicit ordinary Kitty/Sixel complete-frame output |
| TEXT | Raster unavailable, forced text, or recoverable presentation failure |

Terminal's ordinary raster selection prefers verified Kitty, then verified
Sixel. It does not replay a failed Kitty write through another backend.
`--raster` bypasses persistent negotiation; `--text` forces text.

## Accepted evidence

- The complete .NET 10 Release suite passed locally with 1,366 tests.
- Focused full-coverage and 1/4/16/64 workload tests verify one combined update
  for complete atlas damage and sparse updates otherwise.
- The current sample has maintainer acceptance for supplied artwork, immediate
  input, movement, water collision, camera scrolling, help restoration, resize
  cleanup, and independent Q/Escape exits across its recorded ATLAS, FRAME, and
  TEXT observations.
- Terminal 1.28.0's source-built Kitty 0.49.2 witness verifies acknowledged
  persistent-region transactions, frame selection, and disposal.
- Package validation restores and runs package-only consumers for .NET 8, 9,
  and 10 and verifies the Terminal-only direct dependency boundary.

## Known limits

Acknowledged operations establish ordered completion, not atomic or gapless
physical presentation. Emulator-specific flicker or transient resize artifacts
can remain visible. Historical Kitty 0.32.2 evidence records a missing
animation-upload acknowledgement; no identifier workaround, raw protocol path,
or hidden backend retry is included in DCurses. A current recoverable atlas
presentation timeout causes the sample to abandon the uncertain atlas and use
TEXT.

These limits do not weaken lifecycle safety: ambiguous committed failure still
requires recreation, and DCurses never reuses uncertain persistent identity.
