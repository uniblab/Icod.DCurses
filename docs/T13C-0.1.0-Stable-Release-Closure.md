---

## 1. Purpose

T13C closes the first stable `Icod.DCurses` release after the public-API regret
pass and the published Icod.Terminal 0.3 downstream-acceptance checkpoint.

This tranche is intentionally release-focused. It does not add a new DCurses
feature family or change the accepted 0.1 public contract.

## 2. Stable dependency freeze

The stable direct runtime dependencies are:

```text
Icod.Terminal 0.3.0
Icod.TermInfo 1.4.1
```

Alpha-22 validated the Terminal 0.3 architecture using the published
`Icod.Terminal 0.3.0-alpha.8` / `Icod.TermInfo 1.3.0` checkpoint. T13C advances
the package to the subsequently published stable dependency versions without
reintroducing a private terminal reader, parser, response router, or terminal
capability database in DCurses.

## 3. Stable package identity

T13C assigns:

```text
Version         0.1.0
```

`Version` and `PackageVersion` remain synchronized. The assembly-version policy
is unchanged.

## 6. Stable validation gate

Before merging the T13C release commit:

1. Debug, Staging, and Release solution builds SHALL remain clean for `net8.0`,
   `net9.0`, and `net10.0`.
2. The ordinary test suite SHALL pass under all three target frameworks.
3. All six sample projects SHALL build under all three target frameworks as part
   of the solution.
4. The stable package SHALL pack all three target-framework payloads successfully.
5. Structural package verification SHALL pass for all three framework payloads,
   dependency groups, XML documentation files, and portable PDBs.
6. The isolated package-only consumer SHALL restore, compile, and execute under
   `net8.0`, `net9.0`, and `net10.0` using the stable dependency graph.
7. The PR Release/package-only matrix SHALL pass on Windows, Ubuntu, and macOS.
8. `git diff --check` SHALL report no whitespace errors.

After merge:

1. the ordinary `main` validation matrix SHALL pass on Windows, Ubuntu, and
   macOS;
2. only then may annotated tag `v0.1.0` be created;
3. publication SHALL occur only through the tag-controlled release workflow;
4. NuGet.org, GitHub Packages, GitHub Release assets, and SHA-256 checksums SHALL
   all be verified after publication.

## 7. Completion criterion

T13C is complete when a fresh consumer can install `Icod.DCurses 0.1.0`, restore
its stable runtime dependencies without repository-local project references,
build against the public API, and the tag-controlled three-host release workflow
publishes the validated package successfully.
