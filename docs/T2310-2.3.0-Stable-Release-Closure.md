## Scope closed

Version 2.3.0 published the additive `CursesRasterAtlas` feature line,
complete-frame raster fallback, recoverable presentation-timeout fallback,
full-atlas update coalescing, supplied sample artwork, and the public
ATLAS → FRAME → TEXT acceptance sample.

The release preserved:

- `AssemblyVersion 2.0.0.0`;
- `net8.0`, `net9.0`, and `net10.0`;
- exactly one direct runtime dependency, `Icod.Terminal 1.28.0`;
- the frozen 105-type, 839-line public API fingerprint with SHA-256
  `b86ba658fd90d041eeccf5345ecc71a978bea785f0b2bbb9b8274091ccc4afc1`.

## Accepted limits

Acknowledged Terminal operations establish ordered completion, not universally
atomic or gapless physical presentation. Emulator-specific flicker and transient
resize artifacts remain possible. Ambiguous committed failure still requires
application-driven recreation; DCurses does not reuse uncertain persistent
identity, emit a raw protocol workaround, or silently select another backend.
