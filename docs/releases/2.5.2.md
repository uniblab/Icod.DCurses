# Icod.DCurses 2.5.2

Icod.DCurses 2.5.2 is a focused Windows console interoperability maintenance
release. It updates the sole direct runtime dependency to Icod.Terminal 1.29.2
while preserving the complete 2.5 DCurses public API and retained-presentation
behavior.

## What changed

- System-backed Windows sessions temporarily select UTF-8 console-output
  decoding, so Unicode box-drawing characters retain one-cell geometry instead
  of expanding into OEM-code-page text that corrupts borders and layout.
- Windows Raw and CBreak sessions explicitly own mouse input and suppress
  Quick Edit while active, allowing Terminal mouse reports to reach the existing
  DCurses event and interaction layers reliably.
- Session cleanup restores the exact prior console input mode and output code
  page. Partial setup, lifecycle release and re-entry, and final disposal retain
  the same restoration guarantee.

These corrections are supplied by Icod.Terminal 1.29.2 at the platform boundary.
DCurses already delegates system-console setup, input discipline, terminal mouse
protocols, and output to Terminal, so no DCurses runtime implementation change is
required.

## Mouse reporting remains explicit

Terminal 1.29.2 corrects Windows console-mode ownership beneath mouse reporting;
it does not enable terminal mouse protocols automatically. Applications still
acquire a `CursesInputProtocolLease` through `AcquireInputProtocolsAsync`.
`ButtonEvents` requests press, release, and wheel activity. Applications that
implement selection or other pointer drags request `ButtonMotion` instead.

The editor sample now explicitly acquires keyboard event-type, bracketed-paste,
focus, and button-motion reporting. The interaction sample also requests
button-motion reporting for its captured popup drag. Each lease is released
before the owning session restores the terminal.

## Suggested Windows verification

From the repository root, run the color sample to inspect cell-aligned borders,
the editor sample to exercise clicks, selection drags, and scrollbar drags, and
the input showcase to inspect mouse events directly. Exact commands and expected
observations are recorded in [`samples/README.md`](../../samples/README.md).

## Documentation organization

All 23 development roadmaps now live under `docs/` rather than the repository
root. Their internal links, related documentation references, and roadmap path
examples were rebased to the new locations. The concise package README otherwise
remains unchanged apart from its roadmap link.

## Compatibility

- No public API changes.
- `AssemblyVersion` remains `2.0.0.0`.
- Target frameworks remain .NET 8, .NET 9, and .NET 10.
- C# 13 and AnyCPU package behavior are unchanged.
- The only direct runtime dependency remains `Icod.Terminal`, now at 1.29.2;
  Icod.TermInfo remains transitive.
- Raw-mode `Ctrl+C` and `Ctrl+Z` application delivery and legacy `Alt+F` input
  from the 2.5.1 release remain available.

## Install

```text
dotnet add package Icod.DCurses --version 2.5.2
```
