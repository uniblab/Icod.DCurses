# Icod.DCurses 2.5.1

Icod.DCurses 2.5.1 is a focused input-compatibility maintenance release. It
updates the sole direct runtime dependency to Icod.Terminal 1.29.1 while
preserving the complete 2.5 public API and retained-presentation behavior.

## What changed

- Raw-mode sessions now reliably surface `Ctrl+C` and `Ctrl+Z` through the
  DCurses event stream as `CursesKey.Character` events with
  `CursesKeyModifiers.Control`.
- Legacy Alt-prefix input, including `Alt+F`, benefits from Terminal 1.29.1's
  corrected decoding through the existing DCurses adapter.
- Permanent byte-level acceptance coverage protects `Ctrl+C`, `Ctrl+Z`, and
  legacy `Alt+F` delivery from the Terminal session through
  `CursesSession.ReadEventAsync`.

## Choosing an input mode

DCurses continues to default to `CursesInputMode.CBreak`. That mode keeps host
signal processing enabled, so applications that want conventional interrupt and
suspend behavior do not need to change anything.

Applications that use `Ctrl+C` for copy, `Ctrl+Z` for undo, or otherwise own
control-key policy should open the session with `CursesInputMode.Raw`. In raw
mode, the application is also responsible for providing its own exit and
job-control policy.

## Compatibility

- No public API changes.
- `AssemblyVersion` remains `2.0.0.0`.
- Target frameworks remain .NET 8, .NET 9, and .NET 10.
- The only direct runtime dependency remains `Icod.Terminal`, now at 1.29.1;
  Icod.TermInfo remains transitive.

## Install

```text
dotnet add package Icod.DCurses --version 2.5.1
```
