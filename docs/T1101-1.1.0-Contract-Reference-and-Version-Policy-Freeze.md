# T1101 — 1.1.0 Contract, Reference, and Version-Policy Freeze

**Project:** `Icod.DCurses`  
**Release line:** `1.1.0`  
**Tranche:** T1101  
**Development checkpoint:** `1.1.0-alpha.1`  
**Assembly version:** `1.0.0.0`  
**Runtime dependencies:** `Icod.Terminal 1.6.0`; `Icod.TermInfo 1.10.0`  
**Status:** implementation foundation established; semantic representation selection remains T1102

## Purpose

T1101 begins post-1.0 product development without prematurely freezing the public semantic-metadata representation.

The release objective remains semantic cell metadata with retained hyperlinks. This tranche freezes the compatibility, ownership, versioning, and measurement rules that later implementation must obey.

### Assembly-version policy

Compatible additive releases in the 1.x line retain `AssemblyVersion 1.0.0.0`.

NuGet package versions and informational/product versions may advance through 1.1, 1.2, 1.3, and later compatible 1.x releases without creating unnecessary assembly-identity churn. A future breaking compatibility decision may revisit the assembly identity explicitly; it must not change incidentally.

## Terminal 1.6.0 relationship

Terminal 1.6.0 completes its CSI grammar/consolidation and internal terminal/cell pixel-geometry substrate without adding a new public surface. DCurses therefore advances its dependency floor from Terminal 1.5.0 to 1.6.0 without changing the planned 1.1 public design.

Hyperlink protocol ownership continues to use Terminal's already-reviewed typed OSC 8 operations:

```text
TerminalSession.AcquireHyperlinkAsync(...)
TerminalSession.WriteHyperlinkAsync(...)
```

The 1.6 CSI work is useful foundational hardening, but it is not a reason for DCurses to expose CSI or pixel-geometry APIs in 1.1.

## Ownership rules frozen by T1101

1. `CursesStyle` remains visual rendition only.
2. Hyperlink meaning belongs to semantic metadata, not style flags or colors.
3. DCurses never constructs raw OSC 8 framing.
4. DCurses does not expose `TerminalHyperlinkLease` in its public API.
5. Terminal remains the live-session output-ordering, protocol-state, suspend/resume replay, and final-cleanup authority.
6. DCurses owns retained logical semantic meaning and retained physical certainty about whether that meaning has been synchronized.
7. No second terminal input reader or output-serialization domain is introduced.
8. Hyperlink support must compose with synchronized output and the existing DCurses terminal-activity gate.

## Representation decision deferred to T1102

T1101 deliberately does not add `CursesHyperlink`, `CursesCellMetadata`, or a metadata field to `CursesCell`.

T1102 must compare at least these representation families:

- optional immutable metadata reference carried with every cell;
- compact/interned surface-owned token;
- sparse sidecar semantic spans or an equivalent sparse structure.

The selected design must explain:

- ordinary-cell memory cost;
- large-pad memory cost;
- equality and hashing;
- standalone cell inspection;
- copy across screens/pads;
- editing/scrolling/resize behavior;
- wide-cell leader/continuation behavior;
- future semantic extensibility.

## Measurement foundation

`CursesSemanticMetadataRepresentationBaselineTests` establishes a deterministic test-side measurement scaffold using the real `CursesCell` and representative cell-plus-reference / cell-plus-token shapes.

The test intentionally does not freeze one byte count as public compatibility. Its purpose is to make permanent per-cell cost visible to T1102 and to prevent the representation decision from being made solely for API convenience.

The existing approximately half-million-cell pad workload remains the scale reference:

```text
2048 rows × 256 columns = 524,288 logical cells
```

A per-cell increase that looks small in isolation must be evaluated at that scale.

## T1101 exit criteria

T1101 is complete when the exact checkpoint passes the normal PR matrix with:

- `1.1.0-alpha.1` package identity;
- `AssemblyVersion 1.0.0.0`;
- exact Terminal 1.6.0 / TermInfo 1.10.0 package dependencies;
- unchanged stable 1.0 public API fingerprint;
- no new public semantic-metadata type;
- representation-cost baseline tests green.

After that, T1102 may prototype and select the semantic metadata storage model.
